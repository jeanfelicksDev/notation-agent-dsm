# Workspace Rules

- Toujours appliquer et exécuter directement les modifications et commandes de manière proactive sans demander de validation intermédiaire inutile.
- Toujours proposer les deux commandes suivantes après chaque intervention ou modification de code :
  1. **Tester en local** : `npm run dev`
  2. **Déployer en production** : `vercel --prod`
